# Triage labels

Use the default triage vocabulary when an incoming issue needs triage:

| Role | Label |
|---|---|
| Needs initial classification | `needs-triage` |
| Waiting for clarification | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human decision | `ready-for-human` |
| Declined or out of scope | `wontfix` |
